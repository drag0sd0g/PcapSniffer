Instructions (Updated for Version 2.0.0):

This project has been fully modernized. The old build script is no longer needed.

Prerequisites:
- Java 21 or higher
- Maven 3.9 or higher

To build and run:

1. Build the project:
   mvn clean package

2. Run the application:
   java -jar target/pcapsniffer-2.0.0-jar-with-dependencies.jar 64x8burst.eth2.pcap

For detailed instructions, see README.md (English) or README.ja.md (Japanese).

Legacy Instructions (Version 1.0 - Deprecated):
The old buildScript.bat is no longer maintained. Use Maven directly as shown above.
